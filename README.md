# Short Notes Web Application

## Overview
The Short Notes Web Application allows users to quickly add, view, and delete notes in a simple, intuitive interface. The application features a popup form for adding notes, with fields for a title, author, and content. Users can easily manage their notes through the dynamic UI.

## Features
- **Responsive Navigation Bar**: A fixed navigation bar with the title of the application.
- **Popup Form**: A modal popup that appears when the user clicks the "+" button, allowing them to add new notes.
- **Note Management**: Users can create new notes with a title, author name, and text content. Each note includes a "Delete" button to remove it from the list.
- **Dynamic UI**: The interface updates in real-time as users add and delete notes.

## Technologies Used
- **HTML**: Provides the structure for the web page.
- **CSS**: Styles the web page, including the popup modal and overall layout.
- **JavaScript**: Manages the dynamic behavior of the application, such as adding and deleting notes, and controlling the popup modal.

## File Structure
- `index.html`: The main HTML file that contains the structure of the application.
- `index.css`: The CSS file that styles the HTML elements.
- `index.js`: The JavaScript file that adds interactivity to the application.
